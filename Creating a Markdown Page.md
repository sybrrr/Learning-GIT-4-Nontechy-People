# Creating a Markdown Page
I found creating a repository very straight forward but when I went to add a "page," I couldn't figure it out.
The instruction docs kept saying to create a file instead of create a page. 
I had to reseacrch Git vocabluary terms page vs file to learn they are the same. 
I found that in GitHub a page is consider a file so every time you want to add a new page of content to your repository you have to add a page.
[Creating New Files] (https://docs.github.com/en/repositories/working-with-files/managing-files/creating-new-files) 
This article is helpful but it is outdated since the purpose changes button has been udpated to Save Changes. 

# File Types
After learning how to properly emphasis text, I noticed it wasn't working on new repositories I built. Even when I copied and pasted from an working repository. Finally, the file name caught my attention I wasn't adding the proper file extension after the file name. The moment I did all my code activated! **Bold**and  _italics_ everywhere!
**So that's my tip make sure to add your file extensions**
