# Markdown Tips

## Spacing Matters
When you use a markdown symbol where you place in relation to the text determines if it will active.
Huh? What? Which means what exactly. I read this Basic writing and formatting syntax on Git Doc to learn more but still after 
using the material my text wouldn't active to be bold or italics.

## Why? Because spacing Matters!
The article **this is bold text** and this was mine * * this bold text * * which didn't make the text bold. I thought since the # sign
had a space before the text all symbols should be that way. NOPE. I spent way to long trying to emphasize text. 
So here's my tip SPACING MATTERS!
