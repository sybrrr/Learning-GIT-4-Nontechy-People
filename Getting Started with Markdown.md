# Markdown Tips

##### **Things I learned while working with Markdown.**

## 1. If your Text Emphasis is Not Working, check your symbol placment.

When you use a markdown symbol where you place in relation to the text determines if it will active.
Huh? What? Which means what exactly. I learned the symbols but my text wouldn't active to become bold or italics. The article made no mention of it but spacing matters. 
and I thought since the # sign had a space before the text all symbols should be that way. ##NOPE##, I spent way to long trying to emphasize text. 

I read this: [ Basic writing and formatting syntax on Git] (https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax#styling-text).
