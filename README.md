
# A space to Learn-Git-4-Nontechy-People
 
_This hub is for beginners,_  we who don't yet speak Git or technical language with confidence. We are the learners.

My goal here is to write and rewrite about Git's concepts as a way to understand the program better. Along the way, I want to document the mistakes I make and how I recover from them, so other beginners don't get stuck where I did. 

I also want to create small projects around the questions I have because I learn Git best by using it, not just reading about it and to show that these same habits, version and review and publish, apply to writing and documentation, not just code.
